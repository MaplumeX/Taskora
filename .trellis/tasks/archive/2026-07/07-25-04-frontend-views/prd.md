# Frontend Views

## Goal

实现 Things3 风格的核心 GTD 视图与交互，让用户能完整地收集、组织、执行任务。

## Background

- Parent task: `07-25-gtd-app`
- 依赖 `02-backend-core`（API）+ `03-frontend-core`（脚手架与 API 层）完成
- 参考产品：Things3 的视觉风格与交互

## Requirements

### 核心视图

- **Inbox（收件箱）**：显示未分配 project/area 且未排期的任务；快速添加任务
- **Today（今天）**：显示 dueDate 为今天或已过期的任务
- **Upcoming（未来）**：按日期分组显示未来有 dueDate 的任务
- **Anytime（任意时间）**：显示分配了 project/area 但未排期的任务
- **Someday（某天）**：显示标记为 Someday 的任务
- **Projects（项目）**：列出所有项目；点击进入项目详情，显示项目下任务
- **Areas（区域）**：列出所有区域；点击进入区域详情，显示区域下任务与项目
- **Trash（废纸篓）**：显示已删除任务；支持恢复与永久删除

### 任务交互

- 快速添加任务（在任何视图顶部可添加）
- 任务卡片：标题、复选框（完成）、日期、所属 project/area
- 任务详情：编辑标题、备注、设置日期、移动到 project/area
- 子任务（checklist）：在任务详情中添加/完成/删除子任务
- 拖拽排序（MVP 可选，非阻塞）
- 左滑/右键菜单：完成、移动到废纸篓

### 项目与区域管理

- 创建/编辑/删除项目
- 创建/编辑/删除区域
- 项目可分配到区域

### 视觉设计

- 接近 Things3 的优雅简洁风格
- 侧边栏：清晰的导航层级，图标 + 文字
- 任务列表：干净留白、合适的行高、复选框交互流畅
- 配色：Things3 蓝色主题色为主调
- 过渡动画：任务完成时有平滑的动画效果

## Acceptance Criteria

- [ ] Inbox 视图正确显示未分配且未排期的任务
- [ ] Today 视图正确显示今日及过期任务
- [ ] Upcoming 视图按日期分组显示未来任务
- [ ] Anytime 视图显示已分配但未排期的任务
- [ ] Someday 视图显示标记为 Someday 的任务
- [ ] Projects 视图列出所有项目，可进入项目详情
- [ ] Areas 视图列出所有区域，可进入区域详情
- [ ] Trash 视图显示已删除任务，支持恢复
- [ ] 任何视图可快速添加任务
- [ ] 任务可完成、编辑、删除
- [ ] 子任务可在任务详情中管理
- [ ] 截止日期可设置与修改
- [ ] 项目/区域可创建、编辑、删除
- [ ] 视觉风格接近 Things3（配色、留白、过渡动画）

## Out of Scope

- 标签系统
- 重复任务
- 提醒通知
- 日志 Logbook 视图
- 离线编辑
- 拖拽排序（MVP 非阻塞项）
