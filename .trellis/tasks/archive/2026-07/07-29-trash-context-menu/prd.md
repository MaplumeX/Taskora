# PRD — Trash task context menu with restore

## 背景

普通任务行（`TaskItem`）已支持右键菜单（`TaskContextMenu`），项为：标记完成/未完成、计划时间、到期时间、标签、删除。废纸篓页面（`Trash.tsx`）的行是独立简单行：禁用 checkbox + 删除线标题 + 日期 badge + 一个内联「恢复」按钮，无右键菜单。

## 目标

为废纸篓中的任务行也提供右键菜单，并把末尾的「删除」项替换为「恢复」。

## 需求

### R1 废纸篓行右键菜单
- 在 `Trash.tsx` 的每一行上挂载右键菜单，行为与普通任务行一致：右键弹出菜单、定位到鼠标坐标、点击外部关闭、picker 二级 popover。
- 菜单项（顺序）：标记完成/未完成、计划时间、到期时间、标签、恢复。
- 前 4 项的语义与普通行一致（update / complete / uncomplete / 打开对应 picker）。
- 末项「恢复」调用 `useRestoreTask`，成功后 invalidate 任务列表（任务从废纸篓消失）。

### R2 移除内联恢复按钮
- 删除 `Trash.tsx` 行尾的 `<Button>` 恢复按钮。
- 恢复入口仅保留在右键菜单中，与普通任务行「删除仅走右键」保持一致。

### R3 复用 TaskContextMenu
- 通过为 `TaskContextMenu` 增加变体（`variant: 'default' | 'trash'`，默认 `default`）来复用，而非另建组件。
- `default` 行为完全不变（回归保护）。

## 验收标准

- AC1：在废纸篓任意任务行右键，弹出菜单，含上述 5 项；末项文案为「恢复 / Restore」。
- AC2：点击「恢复」后任务从废纸篓列表消失，并出现在其原本所属视图（与原内联按钮行为一致）。
- AC3：点击标记完成/未完成、计划时间、到期时间、标签，行为与普通任务行一致。
- AC4：`Trash.tsx` 行尾不再有内联恢复按钮。
- AC5：普通任务页面的右键菜单行为与外观无回归（末项仍为「删除」）。
- AC6：中英文文案正确。

## 非目标

- 不改废纸篓行的展开/编辑标题能力（废纸篓行保持简单行）。
- 不引入新依赖。
- 不改后端。
