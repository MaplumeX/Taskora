# 侧边栏底栏新增/设置按钮与标题内联编辑

## Goal

重构侧边栏底栏：左侧"新增"按钮弹出菜单（新增项目 / 新增区域），右侧"设置"按钮收纳主题切换与语言切换；并且新增条目时直接创建一个完全空标题的条目后跳转至详情页、标题进入内联编辑状态。同时让项目详情页与区域详情页的标题支持直接点击编辑。

## Background

- 当前 `Sidebar.tsx` 底栏并排放置 `ThemeToggle` 与 `LanguageToggle` 两个平铺按钮。
- 项目 / 区域的创建走 `ProjectForm` / `AreaForm` 对话框，需要先填表再提交。
- `ProjectDetail.tsx` / `AreaDetail.tsx` 的标题是静态 `<h1>`，编辑需点击"编辑"按钮打开对话框。

## Requirements

### R1 侧边栏底栏新增按钮

- 底栏左侧放置"新增"按钮（图标 + 文案）。
- 点击后弹出下拉菜单，包含两个条目：`新增项目`、`新增区域`。
- 点击任一条目时，**直接创建一个新条目**（不弹对话框），标题传空字符串（`title: ''`，后端 `@IsString()` 允许空串），创建成功后导航到该条目的详情页并触发标题内联编辑。
- 不再在 `Projects.tsx` / `Areas.tsx` / `Sidebar.tsx` 外部暴露旧的"新增"对话框入口时，保留对话框组件本身以供详情页编辑使用。

### R2 侧边栏底栏设置按钮

- 底栏右侧放置"设置"按钮（齿轮图标）。
- 点击后弹出下拉菜单，内含：主题切换项（沿用 `useTheme` 的 cycle 行为，显示当前模式图标 + 文案）、语言切换入口（嵌入或并列现有 `LanguageToggle` 的选项）。
- 设置菜单的内容、行为与现状一致，只是入口收敛到单一按钮。

### R3 项目 / 区域标题内联编辑

- `ProjectDetail.tsx` 的标题变为可点击的内联可编辑文本：默认显示标题；点击后变为文本输入框并获得焦点、全选当前文本。
- 编辑态下：按 `Enter` 提交保存、按 `Escape` 取消；失焦时提交保存。
- 提交时若 trim 后为空：回滚为原标题，不发起更新请求（给出 toast 提示标题必填）。
- 保存成功后更新标题、退出编辑态、toast 成功。
- `AreaDetail.tsx` 标题同样支持上述内联编辑行为。
- 保留并复用现有 `useUpdateProject` / `useUpdateArea` hooks，不改变后端契约。

### R4 新增条目后触发内联编辑

- 从侧边栏新增按钮创建项目 / 区域后，跳转到对应详情页，详情页标题自动进入编辑态并全选。
- 通过路由 state（`location.state.editTitle = true`）传递"进入编辑态"信号，避免全局状态或 SSR 持久化问题。
- 详情页接收不到该 state 时退化为普通展示态（不编辑）。

### R5 i18n

- 为新增的菜单文案、设置按钮、空标题占位（若需要）补齐 `zh` / `en` 本地化。
- 可复用现有 `common:*`、`project:*`、`area:*`、`theme:*` 命名空间。

## Constraints

- 不修改后端 DTO 或 controller 契约（后端 `title` 字段为 `@IsString()`，允许空字符串；无需校验非空）。
- 不破坏拖拽排序逻辑（`SortableProjectItem` / `SortableAreaItem`）。
- 不破坏现有 `ProjectForm` / `AreaForm` 的对话框编辑流程——详情页"编辑/删除"按钮可继续使用对话框。
- 保持现有主题切换的 cycle 行为（light → dark → system → light），不引入三段式选择器。

## Acceptance Criteria

- [ ] 侧边栏底栏显示左侧"新增"按钮 + 右侧"设置"按钮，不再平铺 ThemeToggle / LanguageToggle。
- [ ] 点击"新增"弹出含 `新增项目` / `新增区域` 的下拉菜单。
- [ ] 点击 `新增项目` / `新增区域` 后，无需表单即可创建新条目并跳转到详情页，详情页标题自动进入编辑态并全选。
- [ ] 点击"设置"按钮弹出含主题切换与语言切换的下拉菜单，行为与现状一致。
- [ ] 项目详情页标题点击可直接内联编辑：Enter 提交、Escape 取消、失焦提交、空标题回滚并提示。
- [ ] 区域详情页标题同样支持内联编辑。
- [ ] `zh` / `en` 两种语言下所有新增/变化文案均正确显示。
- [ ] 现有拖拽排序、对话框编辑/删除流程未被破坏。
- [ ] `pnpm --filter frontend lint` / `typecheck` / `build` 通过。

## Out of Scope

- 后端 API 改动。
- 任务（task）标题的内联编辑。
- 侧边栏内项目 / 区域列表条目的内联编辑（仅在列表外的详情页编辑）。
- 主题切换 UI 形态改变（保持 cycle 行为）。
