# 底栏按钮切换动画导致整个窗口滚动

Status: resolved

## 问题

桌面窗口可以整体上下滚动，底栏和侧边栏也随页面移动。

## 原因

`ContentBottomBar` 的两组按钮通过透明度和位移交叉切换。隐藏组仍在 DOM
中，`translate-y-1.5` 将它向下移动 6px。底栏位于窗口底部且未裁切溢出，
因此透明按钮仍将文档的滚动高度撑大 6px。

自绘标题栏采用固定定位，顶部留白计入各栏的既定高度；它不是这次溢出的来源。

## 修复

给底栏添加 `overflow-hidden`，将按钮切换动画限制在底栏内部。
任务列表继续由 `MainContent` 独立滚动，菜单和提示仍通过 Portal 显示。

## 验证

使用项目 Tailwind 生成的 CSS 和相同布局在 Chromium 中测量：窗口高 800px，
标题栏分别为 0px（网页 / 全屏）、28px（macOS）、32px（Windows / Linux）。
修复前文档滚动高度均为 806px，修复后均为 800px；1800px 的任务内容仍能
在主内容区独立滚动，底栏下边缘保持在 800px。

底栏、展开任务工具栏和窗口外壳的 20 项现有测试通过；修改文件的 ESLint
检查和 `git diff --check` 通过。
