# 08: 根页返回退到后台（不再退出进程）

Status: done

Spec：`../spec.md` 用户故事 20（本次修正其措辞与实现）。

## 背景

issue 05 的返回手势级联最后一级是 `app_exit`（Rust `app.exit(0)`）：根页（首页）再按系统返回会**终止进程**。这偏离标准 Android 语义：

- 原生应用（Gmail / 设置 / Play 等）在根页返回是**系统把任务移到后台**（回桌面），进程与 WebView 状态保留，从最近任务/图标回来是原地恢复；`app.exit(0)` 则是杀进程、下次冷启动。
- Google 官方明确「勿在根 Activity 处拦截返回」（会禁用 back-to-home 预测式返回动画）：<https://developer.android.com/guide/navigation/custom-back/predictive-back-gesture>、<https://developer.android.com/codelabs/predictive-back>。
- 「再按一次退出」Toast 也不是标准（Android 13+ 预测式返回下更割裂），本 issue 不采用。

taskora 的 `onBackButtonPress` 监听一旦注册即接管默认返回行为（tauri PR #14133），根页必须显式选择收尾动作；此前选择的是 `exit(0)`，改为退到后台。

## 方案

- 新建仓库内本地插件 `tauri-plugin-background`（`packages/mobile/plugins/background`），对齐 `statusbar` / `reminders` 结构：
  - Kotlin `@Command fun moveToBack` → `activity.moveTaskToBack(true)`；
  - Rust `#[tauri::command] fn move_to_back` → `run_mobile_plugin("moveToBack")`，桌面端 no-op。
  - 必须经插件拿 `Activity`：`ndk-context` 由 tao 以 **Application Context** 初始化（tao PR #1266），Application Context 没有 `moveTaskToBack`（它是 `Activity` 的方法）。
- 删除壳层 `app_exit` command 及其注册。
- `back-navigation.ts` 根页改为 `invoke('plugin:background|move_to_back')`；`capabilities/default.json` 加 `background:default`。
- 已知限制：Tauri WebView 壳拿不到系统 back-to-home 预测式返回动画（原生 Fragment/View 才有）；退到后台仍显著优于杀进程，作为当前最优折中。
