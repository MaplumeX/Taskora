# 05: 全局快捷键 + 悬浮快速添加窗

Status: open

## 背景

桌面端 V1 的核心原生价值：在任何应用中按全局快捷键 → 弹出独立悬浮小窗 → 纯文本输入即存为任务标题（无自然语言日期解析，V1.x 再做届时两端共享解析器入 `shared`）。

依赖：02（Tauri 壳）、03（认证，快速添加需要登录态）。

## 内容

1. 全局快捷键注册（可配置，默认建议与 Things 一致如 Ctrl/Cmd+Space 或自定义）。
2. 独立小型悬浮窗（Tauri 多窗口）：无边框、失焦自动隐藏、填完即走。
3. 输入为纯文本 → 调 `api` 创建任务（默认入 Inbox）。
4. 未登录时按快捷键的处理策略（聚焦主窗口走引导流）。

## 验收标准

- [ ] 任何应用获焦时快捷键都能唤起小窗
- [ ] 提交后任务出现在 Inbox，小窗自动关闭
- [ ] Esc / 失焦关闭不丢已输入内容（或明确丢弃，实现时定并记录）
- [ ] 未登录时行为合理
