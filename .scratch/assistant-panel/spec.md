# Assistant Panel Spec

在不离开当前视图的前提下使用助手：桌面端新增可开关的右侧助手面板（Assistant Panel），与现有全屏模式（`/agent`）并存，是同一组 Conversation 的两种视图。架构沿用 `docs/adr/0003-backend-agent-with-pi-agent-core-byok.md`；术语见根 `CONTEXT.md`。

## 动机

- 现在使用助手要整页跳到 `/agent`，任务列表看不见；助手改了什么只能切回去确认。
- 助手是唯一没有快捷键的主要功能（Quick Find ⌘F、Quick Add ⌘⇧Space 都有）。

## 1. 两种模式与入口

| 入口 | 去向 |
|---|---|
| 侧边栏「助手」 | `/agent` 全屏（行为不变），用于会话管理与长对话 |
| 内容区底部动作条 ✦ 按钮 | 开关面板 |
| 快捷键（见第 4 节） | 开关面板 |
| 面板顶栏 ↗ | 去 `/agent`，打开同一个对话 |
| `/agent` 顶栏「收回到面板」 | 回到上一个页面，并在面板中打开同一个对话 |

- 底部动作条 ✦ 按钮紧挨 🔍 搜索；Hint 显示快捷键；面板打开时为激活态，再点收起。
- 底部动作条在移动端（`md:flex`）和 `/agent` 页本就隐藏，因此面板入口天然只出现在桌面端非助手页面。
- 进入 `/agent`（无论从哪个入口）时，面板自动收起，同一个对话不在屏幕上出现两份。

## 2. 当前对话在两种模式间共享

- 当前打开的 Conversation（`activeConversationId`）从 `Agent.tsx` 的局部 state 提升到全局 store，面板与全屏读写同一个值。
- 规则与现状一致：没有选中或选中的已被删除时，回落到最近更新的 Conversation。
- 流式状态（增量文本、运行中的工具、`agentActive`）同样提升出组件：助手运行中途在面板和全屏之间切换，打字效果和运行状态不中断、不丢失。
- 面板收起时不保持 SSE 订阅；再次打开时按现有逻辑从服务端拉取消息与待批准项。
- 助手的数据改动已经经 Sync Hub（虚拟设备 0）→ Event Stream 到达本地副本，面板不需要额外处理数据刷新。

## 3. 面板布局

- 默认宽 360px，位于主内容区右侧、全高，左侧 1px 分隔线。拖动左边缘可调宽（320px ～ 上限见下），双击边缘恢复默认，聚焦边缘后 ←/→ 每次 16px；宽度存本机。
- 面板始终**推挤**主区、与内容并排，不论视口宽窄、是否在 `/calendar`；不提供覆盖（浮层）形态。
- 主区保底 560px：面板宽度上限取「视口一半」与「视口 − 560」中较小者（但不低于面板下限 320）。
- 侧边栏宽 + 主区保底 + 面板宽放不下时，侧边栏先自动收起（复用侧边栏自身的折叠）；关闭面板或窗口变宽即自动展开。只由面板开关、面板宽度、窗口宽度触发，拖宽侧边栏本身不会把它收起；用户亲手展开 / 收起后即由用户接管，不再自动恢复。
- 点击列表不收起面板（这正是并排使用的意义）；Esc 交给主区，不收起面板。
- 面板内容（相对全屏精简）：
  - 顶栏：当前会话标题（点击展开下拉，可切换最近的会话、新建会话）、↗、关闭。不放抽屉式会话列表，重命名、删除交给全屏模式。
  - 消息流与输入框直接复用 `AgentChatView`：#144 起每轮已按 `AgentTurn` 把过程折叠成一行摘要（「已更改 2 项」），面板与全屏同一呈现，只需收窄外边距。
  - 批准卡片照常出现在消息流中。
  - 未配置 BYOK 时显示与全屏一致的引导（去设置）。
- 开关状态记在本机（刷新、重启后恢复），不跨设备同步。

## 4. 快捷键

| 动作 | macOS 桌面 | Windows 桌面 | Web |
|---|---|---|---|
| 开关助手面板 | ⌘J | Ctrl+J | Alt+J |

- J 当前未被 keymap 占用。Web 端 Ctrl+J 是浏览器下载页，按惯例降级为 Alt 系。
- 面板输入框聚焦时按快捷键收起面板，焦点回到之前的位置；面板打开时自动聚焦输入框。
- 在 `/agent` 页按快捷键等同于「收回到面板」。
- 写入 `docs/keyboard-shortcuts.md`。

## 明确不做

- 移动端面板（移动端只有全屏 `/agent`）
- 面板中的会话重命名、删除
- 选中项作为上下文（见 issue 05，单独评估）
- Quick Find「问助手」入口、选中项右键「让助手…」（后续）
