# Windows 加密会话文件与登录恢复修复

用户要求：将 Windows 桌面登录凭证改为系统加密的本地文件，并修复关闭后重新打开需要登录的问题。

- Windows 使用当前用户 DPAPI 加密会话文件，令牌不以明文落盘。
- 访问令牌与刷新令牌作为一个整体持久化，写入成功后才完成登录或刷新。
- 迁移旧凭据，写入成功前保留原条目；退出登录不复活旧凭据。
- 启动恢复支持只有刷新令牌的会话；重复渲染不重复轮换。
- 网络、超时、5xx 错误保留凭据；明确的刷新 401 清除。
- 主窗口与快速添加窗口协调刷新，等待中的请求在失败时也能结束。
- 存储错误与启动连接失败显示可重试错误。

具体决策见 `docs/adr/0002-windows-dpapi-session-file.md`。
