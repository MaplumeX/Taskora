# 07 备注字段的文本合并（评估）

Status: needs-triage

## Problem

备注（Task / Project / Area 的 `notes`）是长文本，整字段 LWW 下两台设备并发编辑会丢掉一整段。ADR-0007 接受了 LWW 的丢失语义，但对长文本代价明显更高。

## Options

- A. 维持现状，文档化（最便宜）。
- B. 仅对 `notes` 使用文本 CRDT（每条备注一个 Yjs 文档，状态向量作为字段值的一部分同步）；其他字段不变。需要 hub 能合并该字段（Yjs 的合并是纯函数，可以在 hub 执行）。
- C. 三方合并（保留共同祖先，冲突时按行合并）：实现简单，但需要在副本里保存祖先版本。

## Next

先量化：统计多设备用户的并发编辑备注频率（依赖 10 的诊断数据），再决定是否值得做 B。
