# 桌面与网页导航预加载

启动时保留当前页优先加载，当前页代码提交且活跃数据查询及同步完成后，在空闲时间分批准备其他页面。页面代码与首次渲染共用加载入口；预加载不挂载组件。

桌面逐步准备常用页面，再准备日历、回顾、设置与助手。网页仅主动准备项目、区域、随时、计划、收集箱与某天；离线、省流量、2G/3G 或已知低速连接不主动下载。没有 Network Information API 时允许有限常用页面队列。

鼠标停留导航入口 100ms 或键盘聚焦时准备对应代码；项目入口同时准备本地副本的任务、分组和已了结内容。短暂扫过取消预取。数据沿用页面查询定义和 Engine watch，在途读取去重，保留变更订阅供点击接管；未点击时 30 秒停止订阅，结果沿用既有 5 分钟回收规则。换账号或登出清除所有查询及定时器。REST 回退时不额外提前发出项目数据请求。

网页后台模块失败静默结束并清除失败的加载 Promise，实际进入失败页面时仍沿既有 chunk 恢复机制处理。隐藏窗口暂缓后续预加载，退出主界面取消尚未执行的工作。
