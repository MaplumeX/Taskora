## Default Permission

Allows opening an attachment with the system's default app.

#### This default permission set includes the following:

- `allow-open`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`attachments:allow-open`

</td>
<td>

</td>
</tr>

<tr>
<td>

`attachments:deny-open`

</td>
<td>

</td>
</tr>
